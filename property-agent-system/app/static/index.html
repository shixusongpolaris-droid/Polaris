报修理解 Agent

understanding

解析自然语言报修，识别报修类型、设施类型、位置与紧急程度，输出结构化理解结果。

输入报修文本 / 楼栋单元→输出类型 · 紧急度 · 置信度
关键词规则模糊匹配置信度评估

派单决策 Agent

dispatch

综合技能匹配、区域就近、当前负载、历史评分与接单时长，为工单选择最优维修工并生成可解释评分。

输入理解结果 / 维修工池→输出维修工 · 时限 · 评分依据
多因子加权负载均衡先验知识

过程监控 Agent

monitoring

按 SLA 倒计时扫描工单，识别接单超时、处理超时风险，生成预警并升级至人工座席。

输入工单时限 / 状态→输出预警记录 · 升级建议
SLA 扫描分级预警自动升级

闭环验证 Agent

verification

校验完工说明与照片是否满足要求，判定通过或退回整改，保障工单质量与业主满意度。

输入完工说明 / 照片数→输出通过 / 退回 · 验证说明
质量规则完整性校验退回整改

工单编排中心

coordinator

作为多智能体调度中枢，创建 trace、串联各 Agent、沉淀事件流与决策日志，并归档闭环工单。

输入完整工单生命周期→输出trace · 事件 · 指标
流程编排可观测性指标沉淀

小区守护 Agent

community_guard

巡检住户门禁出入，按年龄、独居/慢病等标签计算连续未出门天数，自动生成分级关怀预警。

输入门禁事件 / 住户标签→输出未出门天数 · 风险等级 · 预警
阈值规则风险分级自动巡检

停车收费 Agent

parking

识别车辆进出，按免费时长、小时费率、单日封顶与月卡规则自动计费，沉淀收入、占用与缴费指标。

输入车牌 / 进出时间→输出停车时长 · 应收金额 · 缴费状态
分段计费月卡校验自动收费

三项创新点

让工单系统从自动化走向智能化

  1. 01
    可解释的多因子派单

    技能匹配、区域就近、负载、历史评分加权打分，输出完整评分依据与候选排名，而非黑盒指派。

  2. 02
    全链路 Agent 决策追溯

    每次决策保留 trace_id、rationale、confidence 与耗时，可回放、可评估，为答辩演示提供完整证据链。

  3. 03
    闭环验证与 SLA 自愈

    完工后自动验证，不通过退回整改；SLA 扫描主动预警升级，形成「派单—执行—验证—闭环」自愈环路。
