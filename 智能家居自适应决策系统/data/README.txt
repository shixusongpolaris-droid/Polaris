 （完整路径：D:\Dev\Projects\Polaris\智能家居自适应决策系统\data）
========================================================

【目录结构】

  raw\           原始采集数据（不修改，只追加）
    YYYY-MM-DD.csv         传感器数据，每天一个文件
    YYYY-MM-DD_events.csv  空调开关与用户标记事件
    _ground_truth.json     合成数据的真值参数（仅用于链路自检，真机数据无此文件）

  processed\     处理后的数据（待硬件采集后生成）

  external\      外部公开数据集（如需 CASAS 等，放这里）

  logs\          长期运行日志

  calibrated_params.json   标定结果（UA、C、占用表）
  occupancy_table.csv      真实 7×24 占用概率表

--------------------------------------------------------
 数据从哪里来
--------------------------------------------------------

两种情况都写入 raw\，格式完全一致，因此后续流程通用：

  1）真机采集（硬件到货后）
     先烧录 SmartHome_Collector.ino 到 ESP32，然后：
         python scripts\collect_data.py

  2）合成数据（无硬件时验证链路）
         python scripts\make_synthetic_data.py --days 3
     会额外生成 _ground_truth.json，用于验证标定脚本能否反推真值。

--------------------------------------------------------
 CSV 字段说明（YYYY-MM-DD.csv）
--------------------------------------------------------

  pc_time       电脑端记录时间（精确到毫秒）
  raw           ESP32 原始输出行（完整保留，作为原始证据）
  ts_device     设备时间戳（NTP 同步；未同步时为 uptime:秒数）
  temp_c        温度 °C
  humidity_pct  相对湿度 %
  light_lux     光照强度 lx
  pir1          区域 A 人体活动（1=检测到移动）
  pir2          区域 B 人体活动
  radar         毫米波雷达：1=有人（含静止）
  sht_ok        1=SHT31 数据正常
  uptime_s      设备运行秒数
  sht_raw       SHT31 模块原始输出（部分格式下存在）
  note          非数据行（芯片信息、提示信息等）

说明：raw 列保留原始输出，即使解析逻辑有 bug，原始数据也不会丢。

--------------------------------------------------------
 事件文件说明（YYYY-MM-DD_events.csv）
--------------------------------------------------------

  ts            事件时间
  event         事件类型（采集开始/结束、空调开启/关闭、用户标记事件）
  ac_on         空调状态（仅合成数据有）
  temp_at_event 事件发生时的室温（仅合成数据有）

真机采集时，用户按回车记录事件，event 列为"用户标记事件"，
之后可手动整理成"空调开启/关闭"并补充设定温度。

--------------------------------------------------------
 标定流程
--------------------------------------------------------

  python scripts\calibrate_from_real.py

  · 读取 raw\ 下所有 CSV
  · 用前向仿真优化反推围护传热系数 UA 与等效热容 C
  · 统计真实 7×24 占用概率表
  · 输出 calibrated_params.json 与 occupancy_table.csv

  加 --truth 参数可与合成数据真值对比，验证标定正确性。

  已验证：用合成数据（真值 UA=250 W/K、C=1.8e6 J/K）做标定，
  反推结果为 UA=249.6 W/K、C=1.792e6 J/K，误差 0.2% 与 0.4%。

--------------------------------------------------------
 采集时长建议
--------------------------------------------------------

  至少 3 天（覆盖工作日与周末），原因：
    · 标定热工参数需要"空调开启"与"空调关闭"两类时段
    · 统计作息分布需要覆盖不同星期，才能区分工作日与周末差异

  电脑需设置为"从不睡眠"，否则采集中断。
