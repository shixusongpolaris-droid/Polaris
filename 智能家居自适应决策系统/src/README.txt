 D:\Dev\Projects\SmartHome\src  —  源代码目录
========================================================

  data_pipeline\   数据管道
                   串口/MQTT 读取、解析、清洗、存储、重采样。

  env\             环境定义（项目技术核心之一）
                   把家庭环境控制问题实现为 Gymnasium 环境：
                   - 状态空间：温湿度、光照、人员占用、时段等
                   - 动作空间：空调/照明/通风的离散化控制量
                   - 奖励函数：舒适度项与能耗项的加权组合
                   - 状态转移：优先用仿真模型，后期用实测数据校准

  agents\          智能体与算法
                   强化学习算法的训练、评估、调参。

  baselines\       对比基线（论文和答辩必须有）
                   至少包含：固定阈值规则控制、定时控制、单目标 RL。

  control\         决策落地
                   把算法输出的动作转成实际指令：
                   红外控制空调（Broadlink）、智能插座开关等。

【开发顺序建议】
  1. data_pipeline  ——先用假数据把读写跑通
  2. env            ——定义 MDP，这是最关键的一步
  3. baselines      ——先有基线，才能证明你的方法更好
  4. agents         ——训练你的方法
  5. control        ——最后接真实设备
