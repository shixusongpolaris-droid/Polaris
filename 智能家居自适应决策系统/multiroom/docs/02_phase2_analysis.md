# Phase 2 分析：多房间协调间隙 vs PPO（300k）

> 数据：`phase2_results.md` / `.json`；诊断：`phase2_diagnosis.md`
> 场景：8 个随机场景（9100~9107）；5 个 PPO 训练种子；300k 步。
> **合成 B 房间 / 合成作息；不是实测多房间。**

## 一、结果先看

| 策略 | 电费(元/周) | 有人不达标 | 可用? |
|---|---:|---:|---|
| always_on | 54.66 | 0.55% | 贵，但舒适 |
| independent | 22.15 | 6.51% | 便宜，但 B 房间 15.6% 不达标 |
| coord_15 | 23.59 | 3.47% | 协调点：+6.5% 成本，舒适减半 |
| coord_45 | 25.37 | 0.87% | 强基线：接近 0%，+14.5% 成本 |
| PPO es10 | 29.42±4.55 | 6.62% | **被 independent/coord15 支配** |
| PPO es30 | 11.73±3.65 | 48.73% | 便宜，但 **一半时间不舒适** |
| PPO es60 | 11.91±2.64 | 51.88% | 同上 |

## 二、结论（300k 预算下）

1. **协调间隙是真的**：independent 6.51% → coord_15 3.47% → coord_45 0.87%，
   成本 +6.5% / +14.5%；一个简单的“提前 15/45 分钟预冷下一间”就能拿到。
2. **PPO 没有拿到这个间隙**：
   - es10 比 independent 更贵（29.42 vs 22.15），不舒适还略高（6.62% vs 6.51%）；
   - es30/es60 便宜（约 11~12），但 49%~52% 不舒适——不可用工作点；
   - 在 0~6.5% 的可用舒适区，**没有任何 PPO 点比规则便宜**。
3. **PPO 的行为诊断**（场景 9100）：
   - es10 的“空房间开空调”步数：A 209 / B 198 / 外出 196；
   - independent：A 45 / B 24 / 外出 49（大部分是 C3 安全）；
   - PPO 在空房间/外出时大量开空调，却没换来舒适 → 没学会“按占用控制”。
4. **这仍是“高不舒适端才便宜”的老模式**：es30/60 的电费低是以 50% 不达标换来的；
   与单房间的结论一致：RL 只在不可用的高不舒适端有成本优势。

## 三、能不能归因于“训练预算不够”

- 300k 步对 8×8 动作、15 维观测的多房间问题偏少；不能据此说“RL 永远不行”。
- 已补 **1M 步 × es10/30 各 1 个种子** 的预算对照（见 `phase2_results_1m.md`）。
- 1M 结果：
  - es10_s42：**25.96 元 / 4.75%**（同种子 300k 是 29.73 / 7.12%）——明显改善；
  - es30_s42：**10.06 元 / 48.58%**——仍然高不舒适；
  - 但 es10 的 1M 点仍被 **coord15（23.59 / 3.47%）** 和
    **coord45（25.37 / 0.87%）** 支配：更便宜、同时更舒适。
- 判据：1M 仍未在 **≤3.47% 不达标** 时比 coord15 便宜；
  预算有帮助，但没有翻盘。
- 注意：1M 只有 1 个种子；5 种子 1M 是下一步，不能把 1 种子当最终结论。

## 四、和 Phase 0 的关系

- Phase 0 用固定一周 + oracle 协调，得到“GO”：协调 15min 可把 7.14%→3.78%。
- Phase 2 用 8 个随机场景 + 同观测（RL 也看到“下一段/剩余时间”），
  强协调规则仍然有效（3.47%/0.87%），而 PPO 没有学到。
- 差别不在“信息不公平”（观测已对齐），而在**策略学习/训练预算/奖励设计**。

## 五、局限

- B 房间未实测；作息合成；只做 AC；门默认关闭；无总功率上限；无 C4；
- 8 个场景、5 个种子；300k 步；t 值只是近似；
- 没有墙体蓄热/潜热/压缩机循环；没有和真实多房间对照。

## 六、最终判读（当前证据）

1. **多房间的协调间隙是真实的**：independent 6.51% → coord15 3.47% → coord45 0.87%；
   一个简单的“提前 15/45 分钟预冷下一间”就能拿到。
2. **PPO 没有拿到这个间隙**：
   - 300k 5 种子：es10 29.42/6.62（被规则支配）；es30/60 约 11~12 元但 49~52% 不适；
   - 1M 1 种子：es10 25.96/4.75（改善但仍被 coord15/45 支配）；es30 10.06/48.58%；
   - 在 0~6.5% 的可用舒适区，**没有任何 PPO 点比 coord15/45 便宜**。
3. **多房间没有自动让 RL 赢**：协调空间可以被一个简单规则捕获；
   RL 的优势需要更复杂的问题（总功率上限、门动态、灯/通风、 occupant 不确定性、多设备耦合），
   而不是“房间数量”本身。
4. **当前边界结论**：在这个合成 2 房间模型、300k/1M 预算下，
   **强协调规则仍支配 PPO**；这与单房间“规则至少不输”的结论一致。
5. **不能外推**：B 房间未实测、作息合成、只做 AC、8 场景；1M 只有 1 种子。
   如果继续，先做 1M × 5 种子 + 总功率上限/门动态，再谈“RL 是否真有结构性优势”。

## 七、下一步（如果继续）

1. 1M × 5 种子（es10/30），确认 1 种子结果不是噪声；
2. 加总功率上限/门开-关/灯-通风，制造更真实的协调约束；
3. 强基线仍是 coord15/45/MPC；如果 RL 仍不敌，写“边界”；
4. 失败/超时：回退冻结版 `v1.0-single-room-freeze`，不影响结题。
