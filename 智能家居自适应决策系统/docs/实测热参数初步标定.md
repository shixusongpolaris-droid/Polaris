## 2. 方法与原理

### 2.1 一阶热模型

房间集总参数热模型：

```
C · dT/dt = Q_in - UA · (T - T_out)
```

其中：
- `C`  房间等效热容（J/K）
- `UA` 围护结构总传热系数（W/K）
- `T`  室内温度，`T_out` 室外温度
- `Q_in` 室内热源（人、设备、日照）

### 2.2 被动升温过程求时间常数

空调关闭且无人时 `Q_in ≈ 0`，温度按指数趋近室外温度：

```
T(t) = T_out - (T_out - T0) · exp(-t/τ),   τ = C / UA
```

### 2.3 空调开启时用能量平衡求 UA

定频空调以恒定功率制冷、达到设定点后停机，温度呈周期性锯齿波。
在**设定点附近**，房间温度基本恒定（dT/dt ≈ 0），此时：

```
Q_cool ≈ UA · (T_out - T_setpoint) + Q_in
```

若已知空调额定制冷功率，即可反推 UA。

### 3.4 空调降温过程（空调开启，16:26~16:42）

| 指标 | 值 |
|---|---|
| 温度变化 | 25.20 → 21.30 °C |
| 历时 | 16.0 分钟 |
| 平均降温速率 | **−14.62 °C/小时** |

**降温速率比被动升温快 41%**，说明空调制冷能力显著大于围护结构传热。

### 3.5 通风/湿源分析（重要发现）

| 时间 | 温度 | 相对湿度 | **绝对湿度** |
|---|---|---|---|
| 17:29:43 | 22.70 °C | 59.3 % | **11.98 g/m³** |
| 17:39:43 | 25.30 °C | 55.3 % | **12.95 g/m³** |
| 17:48:53 | 26.00 °C | 54.1 % | **13.17 g/m³** |

**相对湿度下降（59.3% → 54.1%），但绝对湿度上升 10%（11.98 → 13.17 g/m³）。**

绝对湿度按 Magnus 公式计算：

```
e_s(T) = 6.112 · exp(17.67·T / (T + 243.5))    饱和水汽压 (hPa)
AH     = 216.7 · (RH/100 · e_s) / (T + 273.15)  绝对湿度 (g/m³)
```

**推论**：若房间完全密封，绝对湿度应恒定。实测上升 10%，说明存在：

1. **通风换气**（室外空气渗入），或
2. **湿源**（墙体/家具升温释湿、植物、人员活动残留）

**对建模的意义**：热模型需要引入换气率（ACH）参数，不能按密闭房间建模。
