## 一、一句话结论

> 在**单房间、单空调、一阶热动态、电价已知**的设定下，修正能量模型与
> C3/C4 安全约束后，**没有任何一个电价格出现统计显著的 RL 优势**；
> 在合成 8 回合（9100~9107）上，规则族拥有唯一的 0.00% 不达标工作点；
> 但真实一周外部验证（10-15~10-21）中最好只有 **0.43%**。
> 旧的“RL 在六格更省 / 规则在低舒适端显著省 24.0%~18.5%”均不能复现，
> 本项目的最强结论是一个**诚实的边界/负结果**，而不是“RL 更优”或“规则全面更优”。

### 2.6 真实占用周外部验证（10-15~10-21）

用项目所有者口述的真实出门/回家时间替换占用（不改环境代码），跑 941 条规则 + 5 个已保存 t1_tou 模型。窗口 7 天，在户率 **69.93%**（与模型 68.4% 接近）；长途为 **626 / 706 / 740 / 959 分钟**（706 是 10-15 实测那次；新增 626/740/959）。

| 项 | 结果 |
|---|---|
| 941 条规则中 0.00% | **0 条** |
| 合成 0% 规则 `C 块[22-23] 睡26 预冷25 h0.8 p0.02` | **2.9586 元 / 4.9582 kWh / 0.43%** |
| t1_tou s42 | 3.1874 / 5.3630 / 0.85% |
| t1_tou s66 | 2.3156 / 3.8657 / 8.09% |
| t1_tou s2026 | 2.9875 / 5.0172 / 2.98% |
| t1_tou s7 | 2.7963 / 4.9647 / 2.55% |
| t1_tou s123 | 2.5879 / 4.3889 / 4.04% |

机制：

- **10-21（626 min）**：当前 hazard 的预冷触发在 675~705 min，晚于实际回家；**漏预冷**，返回 29.36°C，0.43% 不适主要来自这里。
- **10-20（959 min）**：首次 AC 在 12:00 是 **C3 安全强制**（T 将 >30），不是预测；预测触发在 17:18~17:48，已被 C3 掩盖。不能把 3.498 kWh 空开全算成“预测浪费”。
- **10-19（740 min）**：预冷约 19:56，返回 22:01，基本合理；10-15（706 min）也基本合理，但 C3 在 09:30 已把 AC 打开。

**结论**：0.00% 是**合成 8 回合上的点**，不是真实周的普遍保证；真实周最好 **0.43%**。低舒适端规则仍支配 s42（0.43% vs 0.85%，2.9586 vs 3.1874），高不舒适端模型更便宜（s66 8.09% / 2.3156）——**“低舒适规则、高舒适 RL”的方向仍在，但“规则能到 0.00%”必须加限定。** 单周、单 episode、合成天气/热模型，不能当统计显著性。

## 四、仍成立（可写）

1. **C 族主导低不舒适前沿**：32 点中 11 点是 C 族（时段块 + 滞环）。
2. **规则优于恒温全开 25°C**：5.1%（t1_tou）/ 8.7%（t1_flat），合成 8 回合上两者都到 0.00%；真实周最好 0.43%。
3. **电价档位只缩放电费，不改变前沿结构**：t1/t2/t3 同一计费方式的工作点数一致。
4. **分时电价对 RL 相对更不利**：TOU 下 RL 点估计更贵；但单独不显著。
5. **RL 的无人时段电量占比仍高**（30.3%~33.2%），是“空房间制冷”的结构性问题。
6. **恒温设定温度单调**：全开 25→29°C 电量 6.057→1.971 kWh/天。
7. **C3 安全契约兑现**：941/941 触发、0 violation、最高 30.00°C；这是“尽力保证”，
   不是“永远 16~30”的硬状态保证（T_next 仍可能因能力不足越界，届时记 `c3_violation`）。

## 五、方法学警告（必须写进交接）

1. `36ff8e8` 的 reset 修复改变了占用 RNG 流：**同一种子在不同版本的“那一周”不同**。
   实测在户率 66.5%（冻结）vs 65.4%（e9e5bb1），8 回合样本 sd ≈ **2.5pp**，
   足以让规则能量平移 **4~6%**。
2. 因此**不要按同种子逐项相减**说“模型改动导致 XX”；版本对比只能报
   **多种子均值 ± 标准误**。模型净效应只能看 `freeze vs freeze_c3off`（同 RNG 流）。
3. 绝对电费是**模型单位**，不是真实账单；本仿真不能预测真实家庭电费。
4. 规则族与 RL 都看到 `empty_steps` / `p_arrive_soon`；规则不是“自己会预测”，
   而是对风险表查询值做阈值触发。风险表来自生成器本身且过尖（单一 712 分钟长途），
   “预测”优势大概率被高估。

## 六、能写 / 不能写

**能写：**

- 修正能量模型与 C3/C4 后，六格没有显著 RL 优势；
- 在合成 8 回合上，规则族是唯一能到 0.00% 的工作点（3.2956 元，t1_tou）；
- 规则相对恒温全开 25°C 省 5.1%/8.7%（合成 8 回合；真实周最好 0.43%）；
- 本项目的主要贡献是**可复现的评测/审计流程 + 三个方法学教训 + 诚实边界**。

**不能写：**

- “RL 显著更省”“规则在低舒适端显著省 24.0%/18.5%”“六格 RL 胜负”；
- 任何旧能量模型下的绝对电费、六格差值、`energy_scale` 四行 t；
- “预测让规则省 32%”作为独立预测效应；
- “C3 永远保证 16~30°C”（它是尽力保证 + violation 计数）；
- “规则能到 0.00%”作为普遍保证（只在合成 8 回合上成立；真实周 0 条 0.00%）；
- “多房间/真实家庭”结论（未做）。
