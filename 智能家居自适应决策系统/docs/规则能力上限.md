## 一、为什么要做这个实验

此前所有"RL 优于规则"的结论都基于一条比较朴素的规则：

```
无人在房间 -> 关空调
谷段 -> 25 °C   平段 -> 26 °C   峰段 -> 28 °C
滞环 ±0.5 °C
```

这条规则没有用天气预报、不做预冷、参数也未调优。
若用它当基线，"RL 获胜"可能只是赢了一个随手写的规则。

本实验把规则族做参数网格搜索，取其帕累托非支配点作为"规则的能力上限"，再看 RL 是否仍然占优。

## 二、规则族定义

    R1 基础分时规则     谷/平/峰 三个设定温度
    R2 预冷规则         R1 + 若未来 1~2 小时内进入峰段，
                        则当前目标温度再降 precool 度
