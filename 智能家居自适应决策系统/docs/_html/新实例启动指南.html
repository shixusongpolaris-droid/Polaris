一、最省事的做法：直接粘贴下面这段

新建会话后，把下面整段复制粘贴给助手（不用改任何东西）：

工作区在 D:\Dev\Projects\Polaris\智能家居自适应决策系统
（git 仓库根是 D:\Dev\Projects\Polaris，分支 main）

请先按顺序读完这四份，再动手：
1. docs/任务交接.md          （15+1 章，必读，含五条铁律）
2. docs/研究全记录.md        （8 阶段流程 + 74 份报告索引 + 11 处错误清单）
3. docs/结题引用守则.md      （写材料前必读：风险数字与正确说法）
4. docs/项目核心结论.md      （主结论，注意可能是旧版）

环境：
- Python: <项目根>\.venv\Scripts\python.exe
- 需要 PYTHONUTF8=1
- 改任何代码后先跑 scripts/test_env.py（六项自检）

习惯要求（重要）：
- 给我确切的、客观的评价，不要刻意迎合我
- 每次做实验前先审计代码，做完再审计结果
- 团队插件（Agent Teams）可用，团队 ID 是 polaris-audit
- 不显著的结果只能报"未确认"，不能报"无效"

读完告诉我：当前结论是什么、还有什么待办、有没有在跑的任务。

二、开工前必须做的三件确认

助手读完文档后，让它先跑这三条：

# 1. 工作区是否干净（有没有未提交的东西）
& 'D:\Dev\Tools\Git\cmd\git.exe' -C 'D:\Dev\Projects\Polaris' status --short
#   空 = 干净

# 2. 环境是否正常
$py = 'D:\Dev\Projects\Polaris\智能家居自适应决策系统\.venv\Scripts\python.exe'
$env:PYTHONUTF8 = '1'
& $py '<项目根>\scripts\test_env.py'
#   应该六项全过

# 3. 有没有后台任务在跑
Get-Process python -ErrorAction SilentlyContinue | Where-Object { $_.CPU -gt 100 }
#   如果有，先问用户这是不是上次没跑完的

三、如果助手说"读不到文件"

常见原因与解法：

症状 原因 解法
说文件不存在 路径写错（中文目录） 用绝对路径 + 引号
打不开 .md 本机没有关联 .md 程序 让助手跑 scripts/md2html.py 转 HTML，双击 docs\_html\*.html
链接点不开 我给的 markdown 链接用了反斜杠 让助手用 <正斜杠路径> 格式
