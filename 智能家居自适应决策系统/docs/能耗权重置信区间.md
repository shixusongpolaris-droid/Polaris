# energy_scale 置信区间实验

- 生成：2026-10-18 17:59:23
- energy_scale：[10.0, 30.0, 60.0, 100.0]
- 种子：10 个；训练各 300,000 步；评估各 8 回合
- 场景：启用分时电价，`lookahead_weight=0.6`

## 一、为什么需要这个实验

此前的权重结论只有 2~5 个种子，无法判断"RL 优于规则"是否稳健。
某些档位（如 `energy_scale=30`）在不同配置下给出 5.421 与 7.199 两种结果，差异达 33%。
本实验用 10 个种子给出 95% 置信区间，并用**区间不重叠**作为保守的显著性判据。

## 二、规则基线

规则按分时电价区分设定温度：谷段 25 °C、平段 26 °C、峰段 28 °C；
无人在房间时关闭空调。

| 电费(元/天) | 1.646 ± 0.190 |
