## 一、修复内容

`RewardCalculator.temp_cost` 在舒适区间内部原本也施加"趋向区间中心"的梯度：

```python
center = (T_low + T_high) / 2.0
return 0.05 * c.alpha_hot * abs(temp_in - center), 0.0
```

无人区间的中心是 (16+30)/2 = 23 °C，因此在无人时段也惩罚"温度偏离 23 °C"，诱导策略给空房间制冷。

修复：**无人时不施加该梯度**（越界惩罚仍保留）。
