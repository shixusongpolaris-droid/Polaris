## 五、局限（答辩要主动说）

1. **单房间、单空调、一阶热模型**：没有多房间耦合、墙体蓄热、潜热/湿度耦合、压缩机循环；
2. **天气是固定正弦**：没有逐日/季节变化；
3. **空调功率/COP 没有功率计实测**：绝对电费是模型单位，不是真实账单；
4. **热模型是前向欧拉灰盒**：AC 项在 `ac_coef=1.83` 时可过冲 0.1~0.8°C；设定点附近的绝对轨迹不完全物理；
5. **实测只有 2 天/1 人/1 季**：参数可辨识性差；占用 hazard 表过尖；
6. **30 个 RL 模型是旧能量模型训练**：重评≠重训；低舒适端 RL 模型未保存；
7. **真实周验证只有 1 周、单 episode**：不能当统计显著性；
8. **没有闭环硬件**：中央空调无接口，控制实验全在仿真。

## 六、答辩口径

### 一句话

> 在单房间、单空调、电价已知的设定下，修正能量模型与安全约束后，
> 没有统计显著的 RL 优势；规则族在合成 8 回合上能到 0.00%，
> 但真实一周最好 0.43%。本项目最值钱的是“可复现的评测/审计流程 + 诚实边界”。

### 评委可能问

| 问题 | 回答 |
|---|---|
| 为什么 RL 打不过规则？ | 单房间、一阶热、已知电价下，最优策略接近阈值型，规则族能表达阈值；RL 的优势要在多房间/不确定性/未知动力学里才显现 |
| 规则基线是不是故意做弱？ | 941 条、被独立审计员补强 3 次；没有弱化基线；反而多次让 RL 更难赢 |
| 仿真真实吗？ | 热参数用 49.9h 实测标定、能量模型物理自洽；但天气/功率/舒适度是简化，结论只在这个校准过的单房间模型内成立 |
| 为什么结论变了好几次？ | 修了能量模型（净降温→gross cooling）、C3/C4、启动损耗、真实占用；每次都有独立复核；旧数字作废清单在最终结论里 |
| 多房间呢？ | 未做；是未来工作。多房间会引入耦合/协调/组合动作，可能给 RL 结构性机会，但不保证；先做协调间隙诊断再投入 |
| 这个项目有什么贡献？ | 一套从实测到审计的完整流程；三个可迁移的方法学发现；一个诚实、可复现的边界结论 |
