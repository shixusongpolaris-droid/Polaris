## 方法

空调运行时周期性启停，整段数据是被驱动的，不能用单一指数拟合；
扫描平衡温度做指数拟合还会落入退化解（平衡温度取很远时指数近似
直线，RMSE 反而更低）。

因此只取**空调关闭后的最初一段**（接近纯自由响应）计算升温斜率：

```
dT/dt = (T_out - T)/tau + G
```

该式的斜率对 T 的依赖关系为 -1/tau，用多个「同条件、不同起始温度」
的关空调事件联立回归，即可消去未知的热增益 G。
