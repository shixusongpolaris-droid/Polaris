## 五、文档一致性核对说明

2026-10-16 标定热参数后，docs/项目状态总结.md 与 docs/实验结果报告.md
的**正文保留的是标定前数字**，并在文首以显著提示标注了这一点，
同时给出了标定后的关键结论。

因此 scripts/verify_doc_numbers.py 支持两种核对口径
（通过环境变量 VERIFY_MODELS_ROOT 切换结果来源）：

`
# A. 核对文档正文 —— 对标标定前备份，应 0 处不符
set VERIFY_MODELS_ROOT=models\_oldparams_backup
python scripts\verify_doc_numbers.py

# B. 核对当前模型 —— 对标标定后结果，列出差异清单
python scripts\verify_doc_numbers.py
`

实测结果：

| 口径 | 结论 |
|---|---|
| A. 对标标定前备份 | **0 处不符** —— 正文与其标注的标定前身份完全一致 |
| B. 对标标定后结果 | **9 处不符** —— 即标定带来的全部差异，逐项列于本文件前四节 |

这样处理的目的：既保证文档数字可追溯、无编造，
又避免用整篇替换数字的方式掩盖历史结论的变化过程。
