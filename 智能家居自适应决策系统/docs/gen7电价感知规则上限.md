# gen7：电价感知的风险阈值规则（选项 B）

- 生成：2026-10-18
- 场景：semi_markov 占用 + 分时电价，10 回合 x 7 天
- 目的：把电价维度补进规则族，得到更强的基线，避免用「不用电价」的规则去对比会用电价的策略。

## 一、为什么补这一族

`gen7_rule_ceiling.py` 的风险规则**完全没用电价**，它只是「快要回来就开到固定温度」。
而电价是唯一能让「预冷多深」变成二维决策的量：谷段便宜值得压深，峰段贵应该等。

## 二、规则定义

```
有人在              ->  维持 maintain
无人且 p >= 阈值     ->  按电价档位选预冷温度
                        谷段 -> pre_valley
                        峰段 -> pre_peak（可为「不预冷」）
                        平段 -> pre_flat
其余                ->  室温 >27°C 才开，否则关
```
