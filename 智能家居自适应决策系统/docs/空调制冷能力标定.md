# 空调制冷能力标定

- 生成：2026-10-17 22:10:54
- 实测样本：17918 条（49.9 小时）
- 标定样本：9104 个 15 分钟窗口（空调开启且窗口完整）
- 空调设定温度：**23.0 °C**（用户报告，制冷模式）

## 一、为什么必须标定

机制诊断发现：仿真中"全程开空调 25 °C"的平衡室温为 **26.10 °C**，高于有人舒适上限 26 °C，
即空调开满也压不住温度，导致连该基线都有 16.7% 的不舒适率。

自洽性检查给出的直接证据：

```
仿真最大制冷速率 = 2.1475 °C/步 ÷ 0.25 小时 = 8.6 °C/小时
实测最大降温速率                          = 14.9 °C/小时
```

## 二、标定方法

仿真温度更新式：

```
dT = -ua_coef·(T − T_out)                        # 围护传热
     − min(ac_coef·(T − T_set), ac_max_cooling)  # 空调制冷
     + internal_gain·1{有人}                      # 内部热增益
```

移项得实测隐含制冷量：

```
cooling = −dT − ua_coef·(T − T_out) + internal_gain·1{有人}
```

对每个空调开启的 15 分钟窗口计算一个 (T − T_set, cooling) 点，
再拟合 `cooling = min(ac_coef·x, ac_max_cooling)`。

**注意**：`ua_coef` 与 `internal_gain` 保持已标定值不变，
本次只反推空调项的两个参数，以免破坏已标定的热平衡。

## 三、标定数据概况

- (T − T_set) 范围：-3.70 ~ 5.10 °C
- 隐含制冷量范围：-4.693 ~ 4.607 °C/步

## 四、拟合结果

| 参数 | 当前仿真值 | **标定值** | 倍数 |
|---|---|---|---|
| `ac_coef` | 2.0125 | **1.380** | 0.7× |
| `ac_max_cooling` | 2.1475 | **0.85** | 0.4× |

拟合 RMSE = 2.0288 °C/步。

对应的最大制冷速率：

```
仿真   2.1475 °C/步 -> 8.6 °C/小时
标定后 0.85 °C/步 -> 3.4 °C/小时
实测   最大降温 14.9 °C/小时（含同时得热，净制冷应更高）
```

## 五、重要说明：仿真的动作空间无法表达实际设定

实测中用户把空调设为 **23.0 °C**，而仿真动作空间的最低档位是 **25 °C**。
这意味着仿真无法复现实际的最冷设定，属于建模限制，需在报告中说明。
