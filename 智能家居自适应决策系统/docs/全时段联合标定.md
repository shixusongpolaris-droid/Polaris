# 全时段联合标定

- 生成：2026-10-17 02:09:54
- 数据：200 个 15 分钟步（约 50.0 小时）

## 一、为什么必须联合拟合

单窗口解析拟合无法确定 τ，同一段数据换个窗口起止即可得：

| 窗口长度 | τ(分钟) |
|---|---|
| 31 分钟 | 600 |
| 60 分钟 | 23 |
| 78 分钟 | 8 |
| 91 分钟 | 80 ~ 170 |
| 132 分钟 | 25 |

原因：`(T∞, τ)` 退化。短窗口内温度尚未接近平衡，
数据只提供"初始斜率"= (T∞−T₀)/τ 一个信息，
无法拆出两个参数。

联合拟合利用整段数据中的**多次转折**（空调 5 次启停、
日出日落、人员进出），每次转折提供独立约束，
合起来才能把 τ 与 gain 分开。

## 二、模型

```
T' = T + Δt·[ −ua·(T − T_out(t))
              + gain·1{有人}(t)
              + solar·(光照(t)/1000) ]
         − min(ac_coef·max(T − T_set, 0), ac_max)·1{空调开}
```

空调设定温度取实测报告的 **23.0 °C**；Δt = 15 分钟。
